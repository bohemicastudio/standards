# Framework locators

One file per framework: where each concept the checklists refer to lives in that framework, plus framework-specific gotchas. Checklists stay framework-neutral and say things like "read the head/meta config"; the locator tells you which file that is.

Adding a framework: copy `nuxt.md`, fill the table, add one `elif` to `scripts/detect-stack.sh`, and one row to `../detect.md`.
